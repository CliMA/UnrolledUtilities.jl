Supported Iterators

The exported functions support the following statically sized iterators:

  • Tuples and NamedTuples.
  • SVectors and MVectors from StaticArrays.
  • Lazy iterators from Base that wrap statically sized iterators: Iterators.map (Base.Generator), Iterators.reverse, enumerate, and zip.
  • StaticOneTo and StaticBitVector, which are defined in this package. The User Guide explains when to use them.

Other iterator types can be supported through the interface described in the Developer Guide.

Output Container Types

Functions that return containers infer the container type from their inputs:

  • Tuples and lazy iterators give Tuples.
  • SVectors and MVectors give SVectors and MVectors.
  • NamedTuples keep their field names. A function that would change the number of items, such as unrolled_filter or unrolled_push, throws an ArgumentError for a NamedTuple; pass Tuple(nt) or values(nt) to it to get a Tuple.
  • StaticBitVectors give StaticBitVectors when every item of the output is a Bool, and Tuples otherwise. Several StaticBitVectors with the same word type combine into a StaticBitVector.
  • StaticOneTos give Tuples, except in unrolled_take.
  • Inputs with different container types give Tuples, except that a StaticOneTo adopts the container type of the other inputs.

Constant Folding and Bounds Checks

All exported functions are inlined, so that their results constant-fold whenever the compiler knows their inputs, as it does for Vals and for Tuples of Symbols that are constant-propagated. Results that constant-fold can be used as type parameters.

All exported functions propagate @inbounds from their call sites to iterator indexing and to callables that are marked with Base.@propagate_inbounds. @inbounds also elides the checks of compile-time indices, such as N in unrolled_take(itr, Val(N)).

Static Iterator Types

UnrolledUtilities.StaticSequence — Type
StaticSequence{N}

Abstract supertype for indexable iterators with a compile-time constant length N.

Subtypes:

  • StaticOneTo: the integers from 1 to N, without storage.
  • StaticBitVector: N Bools packed into unsigned integers.

Subtypes implement generic_getindex(itr, n) for 1 ≤ n ≤ N and inherit length, firstindex, lastindex, getindex, and iterate.

source
UnrolledUtilities.StaticOneTo — Type
StaticOneTo{N} <: StaticSequence{N}
StaticOneTo(N)

Analogue of Base.OneTo(N) for the integers 1:N that stores N as a type parameter.

The items are known during compilation, so unrolled functions pass constant indices to their callables. Unrolled functions return Tuples for a StaticOneTo, except unrolled_take, which returns a StaticOneTo.

Examples

r = StaticOneTo(4)
unrolled_take(r, Val(2)) # StaticOneTo{2}()
unrolled_map(abs2, r)    # (1, 4, 9, 16)

See also StaticSequence, StaticBitVector.

source
UnrolledUtilities.StaticBitVector — Type
StaticBitVector{N, U, I} <: StaticSequence{N}
StaticBitVector{N, [U]}(bits::NTuple{N, Bool})
StaticBitVector{N, [U]}(ints::Tuple)
StaticBitVector{N, [U]}(f)
StaticBitVector{N, [U]}([bit])

Analogue of BitVector with N Bools packed into words of the Unsigned type U, which defaults to UInt8. The bits are set from a Tuple of Bools bits, from a Tuple of cld(N, 8 * sizeof(U)) words ints, from f(n) for n in 1:N, or to the constant bit, which defaults to false.

Unrolled functions have word-level implementations for StaticBitVectors. They return a StaticBitVector when every item of the result is a Bool, and a Tuple otherwise.

Fields

  • ints::I: Tuple of the cld(N, 8 * sizeof(U)) words of type U.

Examples

bv = StaticBitVector{3}(isodd) # StaticBitVector{3, UInt8}((true, false, true))
unrolled_count(bv)             # 2
unrolled_push(bv, true) # StaticBitVector{4, UInt8}((true, false, true, true))
unrolled_push(bv, 42)   # (true, false, true, 42)

See also StaticSequence, StaticOneTo.

UnrolledUtilities.unrolled_take — Function
unrolled_take(itr, ::Val{N})

Return a container with the first N items of itr, as an analogue of itr[1:N] with a compile-time constant N. Throws a BoundsError unless 0 ≤ N ≤ length(itr).

For a StaticOneTo, the result is StaticOneTo(N).

Examples

unrolled_take((a = 10, b = 20, c = 30), Val(2)) # (a = 10, b = 20)
unrolled_take(StaticOneTo(5), Val(3))           # StaticOneTo{3}()

See also unrolled_drop, unrolled_partition.

unrolled_drop(itr, ::Val{N})

Return a container with all but the first N items of itr, as an analogue of itr[(N + 1):end] with a compile-time constant N. Throws a BoundsError unless 0 ≤ N ≤ length(itr).

Examples

unrolled_drop((a = 10, b = 20, c = 30), Val(1)) # (b = 20, c = 30)
unrolled_drop((1, 2, 3, 4), Val(2))             # (3, 4)

See also unrolled_take, unrolled_partition.

Mapping, Iteration, and Reductions

UnrolledUtilities.unrolled_map — Function
unrolled_map(f, itrs...)

Apply f to corresponding items of itrs, as an analogue of map. The result has length(zip(itrs...)) items.

Examples

unrolled_map(x -> 2x, (a = 1, b = 2))    # (a = 2, b = 4)
unrolled_map(+, (1, 2, 3), (10, 20, 30)) # (11, 22, 33)

See also unrolled_foreach, unrolled_mapreduce, unrolled_flatmap.

UnrolledUtilities.unrolled_foreach — Function
unrolled_foreach(f, itrs...)

Call f on corresponding items of itrs for its side effects and return nothing, as an analogue of foreach. Stops after length(zip(itrs...)) items.

Examples

acc = Ref(0)
unrolled_foreach(x -> (acc[] += x), (1, 2, 3)) # acc[] == 6

See also unrolled_map.

UnrolledUtilities.unrolled_sum — Function
unrolled_sum(itr; [init])
unrolled_sum(f, itr; [init])

Return the sum of the items of itr (or of the values of f(item)), as an analogue of sum. The sum starts from init when it is given; an empty itr sums to init, or to 0 without it. As in sum, Bools and signed (unsigned) integers narrower than Int are added as Ints (UInts).

Examples

unrolled_sum((1, 2, 3, 4))              # 10
unrolled_sum(abs2, (1, 2, 3); init = 5) # 19
unrolled_sum(Int8.((100, 100)))         # 200

See also unrolled_prod, unrolled_cumsum, unrolled_count.

UnrolledUtilities.unrolled_prod — Function
unrolled_prod(itr; [init])
unrolled_prod(f, itr; [init])

Return the product of the items of itr (or of the values of f(item)), as an analogue of prod. The product starts from init when it is given; an empty itr multiplies to init, or to 1 without it. As in prod, signed (unsigned) integers narrower than Int are multiplied as Ints (UInts).

Examples

unrolled_prod((2, 3, 4))              # 24
unrolled_prod(abs, (-2, 3); init = 2) # 12

See also unrolled_sum, unrolled_cumprod.

UnrolledUtilities.unrolled_cumsum — Function
unrolled_cumsum(itr)
unrolled_cumsum(f, itr)

Return the running sums of the items of itr (or of the values of f(item)), as an analogue of cumsum. As in cumsum, Bools and signed (unsigned) integers narrower than Int are added as Ints (UInts), so the running sums of a StaticBitVector are a Tuple of Ints.

Examples

unrolled_cumsum((a = 1, b = 2, c = 3)) # (a = 1, b = 3, c = 6)
unrolled_cumsum(abs, (-1, -2, 3))      # (1, 3, 6)
unrolled_cumsum((true, true, true))    # (1, 2, 3)

See also unrolled_cumprod, unrolled_accumulate.

unrolled_cumprod(itr)
unrolled_cumprod(f, itr)

Return the running products of the items of itr (or of the values of f(item)), as an analogue of cumprod. As in cumprod, signed (unsigned) integers narrower than Int are multiplied as Ints (UInts), and the running products of a StaticBitVector are a StaticBitVector.

Examples

unrolled_cumprod((2, 3, 4))        # (2, 6, 24)

UnrolledUtilities.unrolled_applyat — Function
unrolled_applyat(f, n, itrs...)

Return f(itr1[n], itr2[n], ...) for a run-time index n, with a separate branch for every index in 1:length(zip(itrs...)). Throws a BoundsError when n is outside that range.

Each branch is compiled for the types of the items at its index, so the result is type-stable for heterogeneous itrs when f returns the same type for every index. The branches compile to a switch instruction.

Examples

unrolled_applyat(Float64, 2, (1, 2.0, 3.0f0)) # 2.0

See also unrolled_argfirst, unrolled_findfirst.

Membership, Uniqueness, and Filtering

UnrolledUtilities.unrolled_in — Function
unrolled_in(item, itr)

Return whether item is === to an item of itr, as an analogue of in. Comparing with === keeps the result inferrable for singletons.

Examples

unrolled_in(:b, (:a, :b, :c)) # true
unrolled_in(2, (1, 2.0, 3))   # false, since 2 !== 2.0

See also unrolled_any.

source
UnrolledUtilities.unrolled_unique — Function
unrolled_unique(itr)
unrolled_unique(f, itr)

Return a container with the items of itr whose values of f(item) (or the items themselves) do not appear earlier in itr, compared with ===, as an analogue of unique. A singleton f is called repeatedly and constant folded; any other callable is called once per item.

The number of items in the result depends on the values of f, so the result is only inferrable when those values are known during compilation, as they are for singleton items and for constant-folded f.

Examples

unrolled_unique((:a, :b, :a, :c))       # (:a, :b, :c)
unrolled_unique(abs, (1, -1, 2, -2, 3)) # (1, 2, 3)

See also unrolled_allunique, unrolled_filter.

UnrolledUtilities.unrolled_filter — Function
unrolled_filter(f, itr)

Return a container with the items of itr for which f(item) is true, as an analogue of filter.
