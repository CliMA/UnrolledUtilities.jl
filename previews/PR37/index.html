UnrolledUtilities.jl

Compile-time loop unrolling for statically sized iterators, for type-stable and allocation-free code on CPUs and GPUs.

UnrolledUtilities — Module
UnrolledUtilities

Compile-time loop unrolling for statically sized iterators, such as Tuples, NamedTuples, SVectors, StaticOneTos, and StaticBitVectors. The exported functions are unrolled analogues of functions from Base and Base.Iterators that stay type-stable and free of allocations for long and heterogeneous iterators, which lets them run in GPU kernels and constant-fold results that are used as type parameters.

  • Modification and slicing: unrolled_push, unrolled_append, unrolled_prepend, unrolled_take, unrolled_drop, unrolled_setindex, and unrolled_insert.
  • Mapping, iteration, and reductions: unrolled_map, unrolled_foreach, unrolled_any, unrolled_all, unrolled_reduce, unrolled_mapreduce, unrolled_accumulate, unrolled_sum, unrolled_prod, unrolled_cumsum, unrolled_cumprod, and unrolled_count.
  • Extrema, searching, and indexing: unrolled_maximum, unrolled_minimum, unrolled_extrema, unrolled_findmax, unrolled_findmin, unrolled_argmax, unrolled_argmin, unrolled_findfirst, unrolled_findlast, unrolled_argfirst, unrolled_arglast, and unrolled_applyat.
  • Membership, uniqueness, and filtering: unrolled_in, unrolled_unique, unrolled_allunique, unrolled_allequal, unrolled_filter, and unrolled_split.
  • Combinators and partitioning: unrolled_flatten, unrolled_flatmap, unrolled_product, unrolled_cycle, and unrolled_partition.

using Pkg
Pkg.add("UnrolledUtilities")

Quick Example

A heterogeneous Tuple can be reduced and indexed without allocations, and a 300-bit StaticBitVector can be counted without allocations:

julia> using UnrolledUtilities
julia> const items = (1.5f0, 2, Val(3), (4.0f0, 5.0f0));
julia> to_float(x::Number) = Float32(x);
julia> to_float(::Val{N}) where {N} = Float32(N);
julia> to_float(t::Tuple) = unrolled_sum(Float32, t);
julia> unrolled_mapreduce(to_float, +, items)15.5f0
julia> apply_at_n(itr, n) = unrolled_applyat(to_float, n, itr);
julia> apply_at_n(items, 4)9.0f0
julia> @allocated apply_at_n(items, 4)0
julia> const bits = StaticBitVector{300}(isodd);
julia> unrolled_count(bits)150
julia> @allocated unrolled_count(bits)0

Issues and pull requests are welcome on GitHub. Development follows the CliMA developer guides. Pkg.test() runs the test suite in a few minutes; the benchmarks behind the comparison tables run when UNROLLED_UTILITIES_BENCHMARK=true is set.
