Cookbook

Short recipes for the situations in which unrolled functions are most often needed. Each recipe runs when the documentation is built, so the outputs shown here come from the current version of the package.

Transform the fields of a NamedTuple

unrolled_map keeps the field names of a NamedTuple, and reductions over its values work on Tuple(nt):

julia> state = (; ρ = 1.2, u = 3.0, θ = 300.0);
julia> unrolled_map(x -> 2x, state)(ρ = 2.4, u = 6.0, θ = 600.0)
julia> unrolled_sum(abs, Tuple(state))304.2

To keep a subset of the fields, pass their names as a Val, so that the selection is known during compilation and the result type is inferred:

julia> select(nt, ::Val{names}) where {names} =
           NamedTuple{names}(unrolled_map(name -> getproperty(nt, name), names));
julia> Test.@inferred select(state, Val((:ρ, :θ)))(ρ = 1.2, θ = 300.0)

Compute a type parameter from a Tuple

The results of unrolled functions constant-fold when their inputs are known during compilation, so they can be wrapped in Val and used as type parameters. Here, the field names that start with a density are selected with unrolled_filter and a predicate that constant-folds:

julia> density_names(::Val{names}) where {names} =
           Val(unrolled_filter(name -> unrolled_in(name, (:ρ, :ρe)), names));
julia> Test.@inferred density_names(Val((:ρ, :u, :ρe, :θ)))Val{(:ρ, :ρe)}()

The predicate uses unrolled_in, which compares with ===. A predicate whose value depends on run-time data does not constant-fold, and the result length then cannot be inferred; see Compilation Limits.

Index a heterogeneous Tuple with a run-time index

Indexing a Tuple with items of different types at a run-time index returns a Union of their types, and most operations on the result then allocate. unrolled_applyat instead applies the function in a separate branch for each index, which is compiled to a switch instruction:

julia> items = (1, 2.0, 3.0f0, (4, 5));
julia> count_bytes(itr, n) = unrolled_applyat(sizeof, n, itr);
julia> @allocated count_bytes(items, 4)0

This is the pattern to use inside GPU kernels, where a Union return type cannot be compiled.

Read through a bounds-checked accessor without bounds checks

Functions that map, reduce, search, or filter propagate @inbounds from their call site to iterator indexing and to callables marked with Base.@propagate_inbounds. To read from an array inside such a function without bounds checks, wrap the read in a callable struct with that annotation:

julia> struct Column{A}
           data::A
       end
julia> Base.@propagate_inbounds value(c::Column, i) = c.data[i]value (generic function with 1 method)
julia> struct ColumnReader{C}
           column::C
       end
julia> Base.@propagate_inbounds (r::ColumnReader)(i) = value(r.column, i)
julia> total(c) = @inbounds unrolled_sum(ColumnReader(c), StaticOneTo(8));
julia> total_checked(c) = unrolled_sum(ColumnReader(c), StaticOneTo(8));
julia> column = Column(collect(1.0:8.0));
julia> total(column)36.0
julia> occursin("throw_boundserror", sprint(code_llvm, total, Tuple{typeof(column)}))false
julia> occursin("throw_boundserror", sprint(code_llvm, total_checked, Tuple{typeof(column)}))true

A closure such as i -> value(c, i) keeps its bounds checks, because closures cannot carry the Base.@propagate_inbounds annotation. The functions that only rearrange items, such as unrolled_take, do not propagate @inbounds; see Constant Folding and Bounds Checks.

Update a bitmask across loop iterations

A StaticBitVector stores up to 256 Bools in 32 bytes, so it can be modified in a loop without allocations, where a Tuple of more than 32 Bools would allocate:

julia> function mark_evens(n_items)
           mask = StaticBitVector{40}(false)
           for i in 1:n_items
               iseven(i) && (mask = Base.setindex(mask, true, i))
           end
           return mask
       endmark_evens (generic function with 1 method)
julia> mask = mark_evens(40);
julia> unrolled_count(mask), unrolled_findfirst(mask)(20, 2)
julia> @allocated mark_evens(40)0

Base.setindex takes a run-time index; unrolled_setindex takes a compile-time index as a Val.
